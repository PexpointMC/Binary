# Binary
Binary is the new PawnCraft.

## What (was) PawnCraft?
PawnCraft was a discontinued project by AVPTag. It was all possible because of a bug called Pawn. It was eventually removed by the creator, Canvas, because it was never finished.
Pexpoint decided to finish that, under Binary.

## How does Binary work?

Binary works sort of like this.

You download Binary to have the modded Minecraft Bedrock experience. You run the installer, and press Launch Minecraft. This will detect if you have Minecraft. If you do not have Minecraft, red text will appear on the window telling you that you cannot continue until you have Minecraft Bedrock. This is the same for Mobile versions. After you press Launch and have the game, it will load Minecraft with mods. You can now load .pawn mods in the "Mods" section in Settings. If you cannot load mods that way, you can also manually add them inside the files. Here is how the devices all work.

## PC (Windows, Mac, Linux)

Linux is currently not supported, along with Mac, so Windows is your only option for now.

Download the .exe from releases, or build the project yourself manually.
